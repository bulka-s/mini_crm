# MCHS CRM

Общий реестр компьютеров и устройств по зданиям, настройки сетей и простые рабочие заметки.

## Возможности

- здания: название, адрес, просмотр устройств отдельно по каждому объекту
- карточка устройства: IP, MAC-адрес, тип, имя, операционная система, телефон, отдел, примечание
- сети настраиваются для каждого здания: название и CIDR-маска; при добавлении устройства доступны свободные IP
- локальная сеть `10.110.X.X` и внешняя сеть `192.168.X.X` — отдельные вкладки и сортировка по IP
- поиск по полям, в том числе по русским буквам без учёта регистра
- задачи как заметки с простым флажком выполнения и сроком
- общий вход с одной учётной записью и опцией запомнить вход на компьютере
- импорт и экспорт CSV для Excel

## Запуск для разработки

Нужны Go и Node.js.

```bash
go run .
```

В другом терминале:

```bash
cd frontend
npm install
npm run dev
```

Откройте [http://localhost:5173](http://localhost:5173). Vite проксирует API на сервер `http://localhost:8080`.

## Сборка для рабочего ПК (без Go)

Go нужен **только на компьютере, где вы собираете программу**. На рабочий ПК копируется один файл `.exe`.

На машине с Go и Node.js:

```bash
chmod +x scripts/build.sh
./scripts/build.sh
```

На Windows:

```bat
scripts\build.bat
```

Скрипт соберёт интерфейс, встроит его в программу и положит файлы в `dist/`:

- `dist/mchs-crm.exe` — для Windows
- `dist/mchs-crm` — для Linux

На Linux можно собрать только Linux-версию одной командой из корня проекта:

```bash
make build
```

Готовый файл появится в `dist/mchs-crm`. Команда установит зависимости интерфейса, соберёт его и встроит в бинарный файл.

Дальше на рабочем ПК:

1. Скопируйте `mchs-crm.exe` в любую папку, например `C:\mchs-crm`.
2. При желании положите рядом уже существующий `database.db` — программа подхватит его.
3. Запустите `mchs-crm.exe` (двойной щелчок или из командной строки).
4. Откройте в браузере [http://localhost:8080](http://localhost:8080).

Go и Node.js на рабочем компьютере **не нужны**.

База SQLite создаётся автоматически рядом с программой (`database.db`). Не удаляйте этот файл, если хотите сохранить данные.

### Первый запуск и доступ с других ПК

Создайте рядом с программой `mchs-crm.env`:

```text
AUTH_USERNAME=admin
AUTH_PASSWORD=задайте-длинный-пароль
```

Ограничьте доступ к этому файлу средствами Windows. Запустите программу на постоянно включённом ПК и разрешите входящие подключения к порту 8080 в брандмауэре для вашей локальной сети. На остальных компьютерах откройте в браузере `http://АДРЕС_ЭТОГО_ПК:8080` (адрес можно узнать командой `ipconfig`). Все клиенты подключатся к одной базе на серверном ПК.

При добавлении или редактировании здания задайте для каждой сети название и адрес с маской, например `10.110.1.0/24`. Маски могут отличаться. Свободные IPv4 хост-адреса этой подсети появятся в подсказке при добавлении устройства; уже занятые адреса останутся в списке устройств. Для подсетей, где сетевой и широковещательный адреса являются назначаемыми, учитывайте особенности маски: приложение не предлагает эти два адреса как свободные.

Флажок «Запомнить меня» сохраняет вход в защищённой cookie браузера на 30 дней. Без флажка сессия действует 12 часов.

Если порт 8080 занят, перед запуском задайте другой:

```bat
set PORT=9090
mchs-crm.exe
```

## Переменные окружения

- `PORT` — порт HTTP-сервера, по умолчанию `8080`
- `DATABASE_PATH` — путь к SQLite, по умолчанию `database.db` в текущей папке
- `AUTH_USERNAME` и `AUTH_PASSWORD` — логин и пароль общей учётной записи; также задаются в `mchs-crm.env`

## API

Здания:

- `GET /buildings`
- `POST /buildings`
- `GET /buildings/{id}`
- `PUT /buildings/{id}`
- `DELETE /buildings/{id}`

Компьютеры:

- `GET /computers?search=&building_id=&network=`
- `POST /computers`
- `GET /computers/{id}`
- `PUT /computers/{id}`
- `DELETE /computers/{id}`
- `GET /computers/export`
- `POST /computers/import` — поле формы `file`

Задачи:

- `GET /tasks?search=&status=&building_id=`
- `POST /tasks`
- `GET /tasks/{id}`
- `PUT /tasks/{id}`
- `DELETE /tasks/{id}`

`building_id=0` — записи без здания. `network` принимает `local` (`10.110.x.x`), `external` (`192.168.x.x`) или `other`. Статус задачи: `new`, `in_progress`, `waiting`, `done`, `cancelled`.

У устройства обязательно укажите IP-адрес или имя. MAC-адрес необязательный, но если указан, он должен быть корректным.

## CSV

Экспорт использует разделитель `;` и кодировку UTF-8 с BOM. Импорт понимает `;` и `,`, MAC-адрес и столбцы «Здание» и «Адрес здания».
