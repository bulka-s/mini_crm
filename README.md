# MCHS CRM

Учёт рабочих компьютеров по зданиям и рабочие задачи: поиск, карточки, разделение сетей, импорт и экспорт CSV.

## Возможности

- здания: название, адрес, просмотр компьютеров отдельно по каждому объекту
- ФИО необязательно и показывается только если у здания включено «Показывать ФИО»
- карточка компьютера: IP, имя, телефон, кабинет, отдел, статус, примечание
- локальная сеть `10.110.X.X` и внешняя сеть `192.168.X.X` — отдельные вкладки и сортировка по IP
- поиск по полям, в том числе по русским буквам без учёта регистра
- задачи со статусами: новая, в работе, ожидание, выполнена, отменена
- импорт и экспорт CSV для Excel

## Запуск для разработки

Нужны Go и Node.js.

```bash
go run .
```

В другом терминале:

```bash
cd frontend
npm install
npm run dev
```

Откройте [http://localhost:5173](http://localhost:5173). Vite проксирует API на сервер `http://localhost:8080`.

## Сборка для рабочего ПК (без Go)

Go нужен **только на компьютере, где вы собираете программу**. На рабочий ПК копируется один файл `.exe`.

На машине с Go и Node.js:

```bash
chmod +x scripts/build.sh
./scripts/build.sh
```

На Windows:

```bat
scripts\build.bat
```

Скрипт соберёт интерфейс, встроит его в программу и положит файлы в `dist/`:

- `dist/mchs-crm.exe` — для Windows
- `dist/mchs-crm` — для Linux

Дальше на рабочем ПК:

1. Скопируйте `mchs-crm.exe` в любую папку, например `C:\mchs-crm`.
2. При желании положите рядом уже существующий `database.db` — программа подхватит его.
3. Запустите `mchs-crm.exe` (двойной щелчок или из командной строки).
4. Откройте в браузере [http://localhost:8080](http://localhost:8080).

Go и Node.js на рабочем компьютере **не нужны**.

База SQLite создаётся автоматически рядом с программой (`database.db`). Не удаляйте этот файл, если хотите сохранить данные.

Если порт 8080 занят, перед запуском задайте другой:

```bat
set PORT=9090
mchs-crm.exe
```

## Переменные окружения

- `PORT` — порт HTTP-сервера, по умолчанию `8080`
- `DATABASE_PATH` — путь к SQLite, по умолчанию `database.db` в текущей папке

## API

Здания:

- `GET /buildings`
- `POST /buildings`
- `GET /buildings/{id}`
- `PUT /buildings/{id}`
- `DELETE /buildings/{id}`

Компьютеры:

- `GET /computers?search=&building_id=&network=`
- `POST /computers`
- `GET /computers/{id}`
- `PUT /computers/{id}`
- `DELETE /computers/{id}`
- `GET /computers/export`
- `POST /computers/import` — поле формы `file`

Задачи:

- `GET /tasks?search=&status=&building_id=`
- `POST /tasks`
- `GET /tasks/{id}`
- `PUT /tasks/{id}`
- `DELETE /tasks/{id}`

`building_id=0` — записи без здания. `network` принимает `local` (`10.110.x.x`), `external` (`192.168.x.x`) или `other`. Статус задачи: `new`, `in_progress`, `waiting`, `done`, `cancelled`.

У компьютера обязательно хотя бы одно из полей: IP, имя компьютера или ФИО. IP, если указан, должен быть корректным адресом.

## CSV

Экспорт использует разделитель `;` и кодировку UTF-8 с BOM. Импорт понимает `;` и `,`, столбец «ФИО» или старые «Фамилия» / «Имя», а также «Здание» и «Адрес здания». ФИО не обязательно.
